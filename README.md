# Griham Spaces

A static storefront built with HTML, CSS, and JavaScript. No build step or server-side service is required.

## Preview locally

Open the folder in Visual Studio Code and run **Launch Griham Spaces website** from the Tasks menu. The preview is available at `http://localhost:8000`.

## Publish for free with Netlify

Netlify can host this static site on its free plan. The published site will have a Netlify URL; using a custom domain may require buying a domain.

1. Sign in to Netlify or create an account.
2. Open [Netlify Drop](https://app.netlify.com/drop).
3. Drag the project folder containing `index.html`, the other HTML pages, `styles.css`, and `script.js` onto the upload area.
4. Wait for the deployment to finish, then open the Netlify URL and check the pages, images, map, and WhatsApp links.

For later updates, upload the updated site folder again from Netlify Drop, or connect a Git repository in Netlify to enable automatic deployments.

Product photography and the map are loaded from third-party services, so those parts of the site need an internet connection.
